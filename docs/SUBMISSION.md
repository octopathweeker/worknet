# Worknet 提交说明

Worknet 让用户以受限预算发布结构化任务，由独立执行器交付、审核和结算。Monad 承担共享任务状态与资金托管；钱包登录、独立 Vault、精确一次性赞助权限与恢复队列构成 requester 平台。

当前源码覆盖 M0–M5、R1–R3。开放 taker/harness 和托管 GUI 执行属于后续阶段；真实浏览器钱包 Human 验收仍在进行。完整能力与限制见 [实现状态](PROJECT-STATUS.md)。

源码为当前工作目录脱敏后的提交，包含协议、合约、平台、GUI 和测试。维护者部署地址、个人资料、账户运行记录、原始日志和演示视频均不附带；如参赛表单需要演示地址或视频，应另行提供经过隐私检查的版本。

测试与提交范围分别见 [验证记录](VALIDATION.md)和[公开提交范围](RELEASE.md)。模型审核不是质量保证，超时付款不代表验证通过，当前实现不代表生产安全审计已完成。
