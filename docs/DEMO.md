# 演示流程

使用 `pnpm demo` 体验本地工作区，或按照[部署说明](DEPLOYMENT.md)部署自己的 Monad Testnet 独立平台。

独立平台演示：

1. 用专门的测试钱包登录，输入 0.5 test USDC 并点击“充值”。兼容账户默认代付，普通钱包按提示确认。
2. 查看充值前显示的自动付款范围，再完成钱包确认。
3. 发布一项链上 Transfer 分析任务，查看执行、复算证据与结算结果。
4. 研究任务选择公开 Monad 文档，阅读结论和对应引文；审核可能拒绝不合格交付。
5. 在折叠的资金与授权管理中查看余额、提回未托管资金或停止自动付款。

不要在演示中显示私钥、访问码、cookie、个人账户资料或原始运行日志。钱包兼容与交易确认须在自己的环境实际验证，软件替身不能替代 Human 验收。
