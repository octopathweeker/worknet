# 界面语言

平台与原团队工作区顶部提供 中文 / EN 选择器。默认中文，选择保存在浏览器的 `worknet-language`，刷新保留并同步同源标签页；浏览器禁止存储时仍可在当前页面切换。

切换只重新渲染界面，不重新挂载应用、不刷新页面，不改变登录、草稿、发布方式、任务/attempt、授权或交易。任务标题、用户输入、交付原文、引用、地址、hash 和 JSON 数据保持原样。模型生成的审核说明及未识别服务消息保留原文；静态下载文档不做机器翻译。

- `apps/explorer/src/i18n.ts`：语言状态、订阅、日期 locale 与翻译函数。
- `translations.ts`：中文文案与英文词典，支持 `{0}` 等插值。
- `LanguageSwitcher.tsx` / `locale.css`：统一入口、可访问名称和窄屏布局。
- `main.tsx` 的订阅组件触发重新渲染，保持原组件实例和状态。

新增界面文案使用 `tr('中文文案')`，并在词典中添加英文。只在展示层调用；不要翻译 API 参数、协议枚举、localStorage 标识、用户任务或签名载荷。动态状态应保存稳定值或原始文案，在渲染时翻译，避免语言切换后残留上一种语言。

检查：`pnpm --filter @agent-task/explorer typecheck`、`pnpm exec tsx --test tests/i18n.test.ts`。浏览器验收应覆盖双向切换、刷新/多标签偏好、未提交表单保留、任务原文保留与 390px 手机布局。
