# 公开提交范围

当前工作目录已脱敏，并以新的 main 根提交发布，main 不继承含个人信息的旧历史。旧历史仅保留在本机备份和本地旧分支中。

包含源码、协议、通用部署模板、依赖锁文件与自动化测试。排除 `.runtime`、环境凭证、数据库、签名 outbox、真实 Cloudflare 配置、历史阶段产物、个人部署 URL、截图、视频和绝对本机路径。历史研究回放所需的私有证据不随源码分发。

提交身份使用通用项目身份。对外只推送经过审查的 main；不要推送包含旧资料的本地历史分支。

测试中存在固定的公开开发账户、无效 token 样例以及上游部署字节码/hash；这些用于协议和安全回归，不是维护者凭证。任何本地链公开开发账户均不得承载真实资产。

运行 `pnpm release:check` 检查已跟踪的文件，再通过 `node scripts/package-source.mjs` 打包已提交的 HEAD。归档只包含 Git 提交内容，不包含未跟踪文件、运行目录或 `.git`。
