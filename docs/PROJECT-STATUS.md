# 实现状态

M0–M5：协议、合约、执行与审核、SDK/MCP、Explorer 和测试网闭环已经实现。

R1：原目标工作区与 Worker 控制界面。

R2：独立 Vault Factory、EIP-7702 精确权限与赞助、真实 Testnet 软件钱包验证。

R3：钱包登录、独立用户与预算、云端执行/审核、单按钮充值与故障恢复。真实钱包 Human 验证进行中，不能将软件钱包或浏览器替身等同于扩展钱包全面兼容。

R4–R6：开放 taker GUI、外部 harness、托管执行和开放市场验收尚未交付。

研究测试曾出现“引文真实但不足以支持结论”的自动审核假阳性，随后增加逐项引文支持审核、范围约束与有限修订。失败任务可拒绝、重开和退款；不宣称任意模型任务必然正确。此快照不携带原始账户、付款明细或维护者环境的验证日志。

用 `pnpm check` 在自己的环境重现构建、类型检查、合约与 Node 回归。合约资金与权限、账户 replay/revoke/expiry、双用户隔离、崩溃恢复、金额编码、充值路由与收据核验均有测试。
